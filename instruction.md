## 📦Быстрая установка (easy-install и auto-install)

Для упрощённой установки zapret можно использовать скрипты [**`easy-install.bat`**](./easy-install.bat) или [**`auto-install.bat`**](./auto-install.bat) вместо ручного выбора стратегии через `general*.bat` и `service.bat`.

> [!IMPORTANT]
> Быстрая установка устанавливает стратегию в автозапуск (Как служба). Для доступа ко всем функциям используйте [**`service.bat`**](./service.bat). Крайне НЕ рекомендуется пользовать [**`easy-install.bat`**](./easy-install.bat) или [**`auto-install.bat`**](./auto-install.bat) на постоянной основе! Это решение для тех кто хочет запустить и забыть, но если что-то сломается вам придётся дольше адаптироваться под [**`service.bat`**](./service.bat).

### easy-install.bat

Интерактивная установка с пошаговыми вопросами. Подходит для большинства пользователей.

1. Запустите **`easy-install.bat`** от имени администратора (скрипт сам запросит права при необходимости).
2. Ответьте на вопросы:
   - **IPSet mode** — режим фильтрации по IP (`none` / `loaded` / `any`). По умолчанию `loaded`
   - **Game filter** — режим обхода для игр (`disable` / `all` / `tcp` / `udp`). По умолчанию `disable`
   - **Auto updates** — автоматическая проверка обновлений (`yes` / `no`). По умолчанию `yes`
   - **Update IPSet list** — обновить список `ipset-all.txt` перед установкой (`yes` / `no`). По умолчанию `no`
   - **Strategy mode** — выбор стратегии (`auto` — автоматически подобрать лучшую через тестирование, `manual` — выбрать вручную из списка). По умолчанию `auto`
3. Если выбран `auto` — откроется окно тестирования стратегий, по результатам которого будет установлена лучшая.
4. Если выбран `manual` — выберите номер стратегии из списка.

### auto-install.bat

Автоматическая установка без интерактивных вопросов.

1. Запустите **`auto-install.bat`** от имени администратора (скрипт сам запросит права при необходимости).

2. Дождитесь пока скрипт сделает всю работу за вас.

### Дополнительные параметры

Оба скрипта поддерживают аргументы командной строки:

- **`--make-template`** — создать файл авто-ответов `answers.txt` с примерами, можно указать свои ответы и поделиться ними.
- **`--help`** — показать справку по использованию.

## ⚙️Дальнейшая настройка

После установки стратегии через `easy-install.bat`, `auto-install.bat` или вручную через [**`service.bat`**](./service.bat), для управления обходом используйте [**`service.bat`**](./service.bat):

- **`Install Service`** — установка сервиса вручную через выбор стратегии.
- **`Remove Serivces`** — удаление сервиса.
- **`Check Status`** — проверка работы обхода.
- **`Game Filter`** — переключение режима обхода для игр.
- **`IPSet Filter`** — переключение режима фильтрации по IP.
- **`Extra Settings`** — дополнительные настройки для продвинутых пользователей: тонкая настройка индивидуальных фейк-пакетов (UDP/QUIC, TCP, TCP Alt, TCP Alt2 fakes для Discord, Game, IPSet, General, Stun), сброс настроек к стандартным (Factory Reset), а также параметры `HostFakeSplit` (ALT9 / ALT3). Поддерживается динамическое подтягивание кастомных `.bin` файлов из папки `bin/` по их понятным именам.
- **`Auto-Update Check`** — Вкл/Выкл автоматическую проверку на обновления.
- **`Update IPSet List`** — обновление списка `ipset-all.txt` актуальным из репозитория.
- **`Update Hosts File`** — обновление файла hosts для починки веб версии телеграма и подключения к голосовому чату Discord.
- **`Check for Updates`** — проверка на обновления.
- **`Run Diagnostics`** — диагностика на распространённые причины, по которым zapret может не работать.
- **`Run Tests`** — запуск утилиты для проверки стратегий на работоспособность.
